Palettes

Click a palette to edit it. Drag a row (⠇) to reorder it, or Copy one and Paste it into another slot (⌘C/⌘V or Ctrl+C/Ctrl+V while the list has focus). The OPTIONS → COLR field picks one 0–7 on the console.

The highlight uses c1 as the block and c2 as the glyph (so a cursor cell reads as c2-on-c1).
Saves/loads just the selected palette (name + 3 colours) as its own small .gmpal file — handy for sharing or backing up one palette without a whole ROM. Import overwrites the currently-selected slot. Import All (next to Export All, left) loads a full .gmpalset and overwrites all 8.

Or export source — paste into pal_table

Patcher: the data follows the "GMDJPAL0" locator in the ROM — 8×3 words, big-endian.
